Add graphics templates and richer text: `title`, `lower-third`, `banner` and `callout` templates built from shapes and text (one undo step) via the new `add_template` MCP tool and an "Add" menu in the editor; a text button and `T` shortcut; font family (sans/serif/mono), italic and outline controls for text, with matching fonts in the server renderer. New overlays now always stack above whatever they overlap in time.
