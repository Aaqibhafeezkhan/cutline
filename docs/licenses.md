## Notes on the non-permissive entries

- **Mediabunny (MPL-2.0)**: file-level copyleft. Cutline uses it unmodified as a dependency, which
  MPL-2.0 permits in MIT projects. If you modify Mediabunny's own files, those modifications must
  stay MPL-2.0.
- **sharp / libvips (LGPL-3.0-or-later)**: pulled in by `@huggingface/transformers`, which is an
  **optional** dependency used only for local speech-to-text. libvips is a dynamically loaded
  native library and is not part of Cutline's code. Installing without optional dependencies
  (`pnpm install --no-optional`) removes it (transcription is then unavailable).

## External programs (not distributed)

- **ffmpeg** (LGPL/GPL depending on the build) is invoked as an external process found on
  `PATH`/`FFMPEG_PATH`. It is not bundled or linked. The Docker image installs Debian's ffmpeg
  package at build time; if you distribute that image, ffmpeg's license applies to it.
- **ffmpeg.wasm core** (`@ffmpeg/core`, GPL) is downloaded from a CDN only when a user opts into
  converting an unsupported file in the browser. Only the MIT wrapper packages (`@ffmpeg/ffmpeg`,
  `@ffmpeg/util`) are dependencies.
- **Whisper model weights** (MIT, OpenAI; ONNX conversion by onnx-community) are downloaded from
  the Hugging Face Hub on first use.
